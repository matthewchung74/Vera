# Sound Assets

## connecting-chime.mp3

A gentle, calming chime sound (~1-2 seconds) that loops while connecting to Vera.

**Requirements:**
- Duration: 1-2 seconds
- Format: MP3
- Style: Gentle, non-intrusive, calming
- Volume: Will be played at 50% volume

**Suggested sources (royalty-free):**
- https://freesound.org (search: "gentle chime", "notification chime")
- https://pixabay.com/sound-effects (search: "soft chime")

Place the downloaded file here as `connecting-chime.mp3`.
